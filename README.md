# T-Invest Analytics

Локальная аналитика по счетам Т-Инвестиций (ИИС + брокерский). React + TS + Vite, CSS-модули.

## Запуск

1. Скопировать `.env.example` в `.env.local` и вставить токены (read-only достаточно):
   ```
   TINVEST_TOKEN_IIS=t.xxx
   TINVEST_TOKEN_BROKER=t.yyy
   ```
2. `npm install`
3. `npm run dev` → http://127.0.0.1:5173

## Как ходят запросы

Браузер не может стучаться в `invest-public-api.tinkoff.ru` напрямую (CORS), а токен не должен попадать во фронт.
Поэтому фронт шлёт запросы на `/api/iis/...` или `/api/broker/...`, а dev-сервер Vite (`vite.config.ts`)
подставляет нужный токен и переправляет запрос в T-Invest REST API. Токены читаются только Node-процессом.

API работает по сертификату Минцифры — корневой сертификат лежит в `certs/` и передаётся прокси явно,
потому что в стандартном списке CA у Node его нет.

## Страницы

- **Сводка** (главная) — что сделать прямо сейчас: напоминания по ИИС, ребалансировка к целевым долям
  (сначала покупки на свободные деньги, продажи — только если иначе не выровнять), что изменилось с прошлого визита,
  выплаты на 30 дней. Целевые доли по типам активов задаются здесь же (по умолчанию план 40 / 35 / 25 / 0 — облигации / фонды / акции / деньги),
  свои для каждого режима шапки, хранятся в localStorage.
- **Портфель** — позиции по обоим счетам (или по одному), стоимость с НКД, P&L, доля, XIRR — годовая доходность с учётом дат пополнений;
  блок «Облигации»: доходность к погашению, дюрация, купонная доходность по каждой бумаге и средние по портфелю.
- **Операции** — вся история: сделки, выплаты, пополнения, комиссии, налоги; фильтры по периоду и типу, суммы за период.
- **Выплаты** — купоны и дивиденды по месяцам за год, календарь будущих выплат и погашений на 12 месяцев вперёд.
- **Структура** — распределение по типам активов, секторам, валютам, инструментам; облигации по сроку и типу купона.
- **Аналитика** — стоимость портфеля по дням против вложений, сравнение с TMOS («а если бы всё в индекс»),
  TWR, XIRR, максимальная просадка, результат по месяцам.
- **ИИС** — планировщик ИИС-3: срок до закрытия без потери льгот, взносы и вычеты по годам (лимит 400 тыс., ограничение
  уплаченным НДФЛ), советы по данным, прогноз стоимости и выгоды до года закрытия. Параметры редактируются и хранятся в localStorage.
- **Рынок** — скринеры. Облигации: все ОФЗ и ликвидные корпоративные с низким риском (рублёвые, фиксированный купон,
  без амортизации) с доходностью к погашению, дюрацией и рейтингом; блок «лучше того, что у тебя» — аналоги той же дюрации
  с YTM выше на 1 п.п. Акции: мультипликаторы (GetAssetFundamentals) и консенсус аналитиков (GetConsensusForecasts).
  Первая загрузка ~1–2 минуты (сотни запросов за купонами, с повторами при 429), затем кэш на 6 часов.

## Кэш

Свечи, купоны и справочник инструментов сохраняются в IndexedDB (`app/queryClient.ts`, неделя жизни),
поэтому «Аналитика» при повторном заходе открывается сразу. Свечи докачиваются инкрементально — только хвост
с последней известной даты. Портфель и операции всегда запрашиваются заново.

## Как восстанавливается история

API не отдаёт стоимость портфеля в прошлом, поэтому она пересчитывается: от сегодняшних позиций
откатываем операции назад (`features/history/holdings.ts`) и получаем состав портфеля на каждый день;
затем умножаем на дневные свечи (`pricing.ts`): облигации — процент от номинала плюс линейный НКД,
валютные бумаги — по курсу дня. Сегодняшняя точка берётся из API как есть.
Бумаги сопоставляются по `positionUid` — одна и та же облигация в сделках и в портфеле может иметь разные `instrumentUid`.

Суммы в валюте (например, купоны юаневых облигаций) переводятся в рубли по текущему курсу Мосбиржи (`MarketDataService/GetLastPrices`).

## Структура

```
src/
  api/        клиент, типы ответов API, работа с деньгами (units/nano)
  app/        layout, роутер, глобальные стили
  features/   summary (сводка, ребалансировка), portfolio, bonds (YTM/дюрация), operations (XIRR), payments,
              allocation, history (график + TWR), iis (планировщик), market (скринеры), instruments
  shared/     account — выбор счёта и запросы по нескольким счетам сразу;
              rates — курсы валют; ui — карточки, таблица, переключатель, диаграммы (SVG)
certs/        корневой сертификат Russian Trusted Root CA
```
